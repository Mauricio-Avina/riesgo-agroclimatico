# Ensayos de operación local · 27 de noviembre de 2026

Se abrió la aplicación con iniciar.bat. Con la API disponible se apagó la radio del adaptador Wi-Fi activo y se verificó que el equipo había perdido la asociación inalámbrica. Ethernet estaba desconectado. Se abrió la ficha de Amealco de Bonfil, temporal, llenado, y el navegador descargó el PDF municipal. Al terminar, se encendió la radio y se confirmó que recuperó la conexión. [Consulta con Wi-Fi apagado](consulta_wifi_apagado.png)

En un segundo escenario se verificó por separado la indisponibilidad de la API y se abrió una sesión nueva del navegador. La aplicación presentó la ficha guardada con el corte climático del 7 de octubre de 2025 y la generación de la copia el 27 de noviembre de 2026. Se descargó el mismo boletín municipal. [Consulta con la API detenida](consulta_sin_conexion.png)
